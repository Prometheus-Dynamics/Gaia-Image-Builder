# Gaia

Gaia builds what a device needs in order to run: OS images, slots, recovery images and packages,
from descriptions of a board, its components and a product. Each build step is a node run by
[Daedalus](https://github.com/Prometheus-Dynamics/Daedalus).

This is the `next` branch, a rebuild in progress. The working tool is on `dev`. Start with
[`docs/design.md`](docs/design.md) and [`AGENTS.md`](AGENTS.md).
