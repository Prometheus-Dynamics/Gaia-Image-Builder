# F11: A small OS change is a short rebuild

**Group:** F. Recipes, graph, command

**Wave:** 10

**Needs:** F8

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Why

A full ZERO 3E OS build took 77 minutes on a loaded machine, and every change to an OS's config (a BusyBox fragment, a blob pin, a permission) pays it again. Measured on that build:

- 92% of the time is the one `gaia.os.buildroot` step.
- It compiled 55 packages, and about 45 are host tools the kernel's and U-Boot's builds need (Python and nine Python packages, OpenSSL, GnuTLS, util-linux, swig, bison, flex, the autotools). They are the same for every board and are rebuilt from source every time.
- The board's own userspace was three packages.
- ccache is off: D2 made the node, and nothing wires it.
- 197 s went to store hits that hashed their trees again (fixed on its own: a verified object is not read again until touched).

Faster disks are not the fix.

## Build, in this order

For each, report before and after on the same build: wall time and the count of packages compiled. Give an idle-machine estimate where one can be made.

1. **Host tools built once.** Either their own step, keyed on Buildroot's version and the set the kernel and bootloader builds need, with the tree reused; or part of the pinned build root (F13), one root serving both. Pick the one that gives a correct result soonest and say which.
2. **The kernel and the bootloaders as their own steps**, each keyed on what it depends on: source, config fragments, device trees and overlays, toolchain; for the bootloader also its blobs and trusted firmware. Keep right:
   - Modules are built against that kernel's build tree (D3 already takes it).
   - The root filesystem still gets `/lib/modules` and `/boot` from the kernel step.
   - The toolchain's kernel headers stay as shipped.
   - The kernel, device trees and each bootloader file are outputs a recipe can take (a flasher needs them with no image).
   - A bootloader's fragments can differ per image: one source, two builds (the OS's, and a flasher's with USB fastboot).
   Then a BusyBox or permissions change rebuilds only the root filesystem's packages.
3. **ccache** for what still compiles (this is F9's cache wiring).

Not here: reusing a previous output tree in place.
