## Build

- How a builder step runs its tool inside a pinned root filesystem (from C3): rootless container or user namespace, input trees mounted read-only, output directory the only writable path, network off unless the step declares it.
- Host limits (CPU set, jobs) are inputs to the step, so they show in its key.

## Proof

Tests: a step can't write outside its output; network is off by default; the same inputs give the same output digest.
