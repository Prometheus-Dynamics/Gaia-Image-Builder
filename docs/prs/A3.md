## Build

- The A2 graph run twice in two processes, using the step kit's look-up-or-make (A1) over the store's step entries (B1). Daedalus reuse is not used.
- Each step computes its key from its node kind, node version, config and its inputs' digests. Source steps take their digest from content (commit, tree digest).
- A hit counts only when every artifact the entry names is present with its digest; otherwise the step makes it again.
- Edit one file in the source: exactly the steps downstream of it make anything.

## Proof

Paste: second run executes zero steps; after deleting one artifact from the store, only that step runs again, and the steps after it run again only when the remade output differs (an identical rebuild leaves their keys unchanged, so they are found); after a one-file edit, only that chain reruns.
