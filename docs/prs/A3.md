## Outside blocks

## Build

- The A2 graph run twice in two processes. Source steps key their outputs on content (commit, file digest), through Daedalus's keyed reuse (X1).
- A Gaia reuse store over the content store: answers a hit only when every artifact the stored outputs name exists with its digest.
- Edit one file in the source: exactly the steps downstream of it rerun.

## Proof

Paste: second run executes zero steps; after deleting one artifact from the store, only that step and its downstream rerun; after a one-file edit, only that chain reruns.
