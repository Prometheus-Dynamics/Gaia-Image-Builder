# F12: The firmware-boot family, and files a tool makes at build time

**Group:** F. Recipes, graph, command

**Wave:** 11

**Needs:** F10, F11

**Runs:** board

Read `AGENTS.md` and `docs/design.md` first.

## Why

The boards whose boot ROM reads a FAT partition itself (no bootloader built) are the main boards, and they need pieces no recipe has yet. Atlas's board files say exactly which fields they want; read its draft board PR for that family before designing.

## Build

- **The boot partition** for this family: `config.txt` from the board's fragment, the command line, the kernel under the name the firmware loads, the device trees, and `overlays/`. This is F10's firmware form; F10's nodes are used as they are.
- **A board's own overlay sources** compiled and placed beside the in-tree ones (`kernel.overlays` already reaches the kernel build).
- **A tool built for the build machine, run at build time.** A component is built for the host, not the board; a step runs it with named inputs (a board's description file, data from a source); its outputs are placed like any install entry: a generated overlay through the device tree compiler into `overlays/`, a boot fragment into `config.txt`, a file into the root filesystem. Design it generically: a file made by a tool at build time will come up again. The run is keyed on the tool's digest and its inputs.
- **A component into the initramfs**: an install entry says which tree it goes to (`into = "initramfs"`).
- **A file assembled from several owners.** A component cannot append to a file the OS owns. One file built by concatenating named fragments from the OS and from components, in a stated order, declared in the product (`/etc/mdev.conf`, and other configuration with no `.d` directory).
- **The slot record** in the form this family's firmware reads (`tryboot`, with the trial-attempts counter file writable from the initramfs).

## Proof

Board run on the main board: it boots the image, the generated overlay is loaded (name the nodes it enabled), and the slot driver lists the slot.
