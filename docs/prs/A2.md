## Build

- Three real steps as nodes: clone a small public git repo at a fixed commit, `cargo build` a crate in it, pack the binary into a sorted tar with fixed timestamps. Minimal versions; C and E replace them.
- Two independent chains built into one graph in code, run by Daedalus with threads, so the two chains run at the same time.
- Fail-fast: a step forced to fail stops the build and the other chain is cancelled.
- A step that fails twice then succeeds, with `Recovery::Retry { max: 3 }`, completes.
- Write down anything Daedalus could not do in the PR description. Don't build it here.
