## Build

- Node: Buildroot source + config fragments + external tree + board kernel/bootloader inputs -> root filesystem tree, kernel, device trees, modules, bootloader outputs, each an artifact.
- Progress from make's package steps into Daedalus progress.
- Config fragments come from descriptions only; no hand-merged defconfigs.
