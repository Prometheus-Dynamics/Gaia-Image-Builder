## Build

- A content-addressed store of files and trees on disk: put a file or a directory tree, get back its digest; get by digest; check presence and integrity.
- Tree digests cover names, modes, symlinks and content, never timestamps or owners of the build host.
- A step's output directory is a scratch area that is committed into the store atomically when the step succeeds and discarded when it fails.
- Step entries: step key -> the output references that step made. Written only after the outputs are committed. This and the content are the whole cache; Gaia keeps no other state between runs.
- Retention: keep what the latest N locks reference, delete the rest on request. No automatic deletion.

## Proof

Tests: same tree gives the same digest on two machines' layouts; a crash mid-commit leaves no partial entry; retention keeps what is referenced.
