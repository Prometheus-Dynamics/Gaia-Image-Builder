# F15: Smaller things the board files need

**Group:** F. Recipes, graph, command

**Wave:** 11

**Needs:** F8

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

Each is its own PR. None needs a Buildroot run.

- **A patch series on a git source**: a list of patches applied to the source at its commit, each pinned by hash in the lock, for a kernel or a bootloader. Note for whoever uses it: a board whose memory-init blob is closed can have a local build that fetches the blob, but no published image may carry it. Publishing images is the user's decision.
- **A named local input**: a file from outside the repository given on the command line (`--input name=path`), hashed into the key, shown in the plan, refused when missing. For a bench SSH key.
- **`kernel-module` as a builder**: a component built against the image's kernel build tree and toolchain (D3's node), so a product can name an out-of-tree module.
- **A minimal usable system, as reference fragments**: one for BusyBox init, one for systemd, commented. The OS config starts from nothing, so each covers what a fragment must turn on to have a way in: the root filesystem writable or not, network bring-up, root's login, a console, BusyBox applets through a BusyBox fragment. Say the rule prominently in the description docs.
- **A notice in `gaia plan`** when an OS has no console login, no network bring-up, or no way in. A notice, not an error: a flasher may want none.
- **A bootloader's sign of life**: a family option that has the bootloader start a USB gadget before it boots, so a board with no serial console shows it reached the loader.
- **The slot record's counter**: `trial_attempts` (0 to 3) in the U-Boot record, a counter file in the firmware form; a first-flash image writes no trial pending.
