## Build

- The types that cross ports, as `#[derive(DaedalusTypeExpr, ToValue)]` with pinned keys: `gaia:artifact` (kind, digest, store path), `gaia:tree`, `gaia:file-entry` (path, mode, owner), `gaia:image`, `gaia:partition`, `gaia:target` (arch, CPU), `gaia:size`.
- Kinds are open (a string from a known list plus `other`), so a `.uf2` or `.ipk` output needs no type change.
- Every type has a value serializer, so it shows in reports and can sit in a reuse store.

## Proof

Tests: each type round-trips through Daedalus values; keys are stable (recorded).
