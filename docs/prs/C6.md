## Build

- Node: a declared command with declared input trees and declared output paths, run in a pinned image. This replaces shell hooks: anything it reads must be an input, anything it makes must be a declared output.

## Proof

Tests: an undeclared output is an error; an undeclared input is not visible to the command.
