## Build

- How a Gaia build step is written as a Daedalus `#[node]`: a step gets a context with its own output directory, a cancel check, a progress call, and a way to run one tool process.
- Running a tool: fixed argument list and environment (nothing inherited), stdout/stderr streamed into Daedalus's fault record and stderr tail, cancel kills the process group, exit status becomes a fault.
- No retry loop, no timeout policy and no scheduling here: those are Daedalus step policy.
- Read Daedalus `docs/node-authoring.md` and `docs/host.md` first.

## Proof

Tests: a tool that prints and exits 0; one that exits 3 (fault names the step and holds the stderr tail); one cancelled mid-run (process group gone, no zombie).
