## Build

- Raze's board, component and product files written fresh in the new form, for the Raze OS as it is meant to be now: Styx camera path (no libcamera, libpisp or their patches), the Lemnos kernel module and lemnosd, orion-node, Atlas's on-board agent, slots as EROFS files with verity. Atlas `devices/raze/` and HeliOS `gaia/configs/` are old; read them by `git show` only to find what a board needs (overlays, firmware, kernel options), never to port them.
- These files are the proof that Gaia can build Raze. Atlas owns the real ones and adopts them afterwards (X2).
- Build the image and compare it file by file with the image `dev` builds; every difference listed as intended or missing.
- Recovery image with Orion's recovery build (X4).
