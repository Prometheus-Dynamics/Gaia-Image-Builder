## Build

- Nodes that read the built image and fail the build: modules and firmware the board description requires are present, kernel config options it requires are set, device tree nodes it names exist, service units have no start limits, every binary's interpreter and libraries exist.

## Proof

Tests: each check fails on a crafted bad image with a message naming the missing item.
