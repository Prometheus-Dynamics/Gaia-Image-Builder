## Build

- Nodes: GPT or MBR layout from the recipe, raw blobs at fixed offsets (bootloaders), filesystem images into partitions -> one disk image; a U-Boot environment partition.
- Offsets and alignment come from the board description.

## Proof

Test: `sfdisk --dump` of the result matches the declared layout; blob offsets checked byte for byte.
