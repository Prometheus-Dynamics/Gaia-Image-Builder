## Build

- One lock file per product: every source resolved to a commit or digest, every container image to a digest, every downloaded blob to a digest. Sorted, stable text.
- Written only by `gaia lock` (F6). A build with a source missing from the lock, or a lock entry that no description uses, fails with the name.

## Proof

Tests: write/read round trip is byte-identical; a stale entry and a missing entry each fail with the name.
