## Build

- The three file formats from `docs/design.md`: board, component, product. TOML, one version field, unknown keys are errors with a suggestion.
- A board file may extend one family file (like `rk35xx/base.toml`). No other inheritance, no imports of fragments, no interpolation language.
- Validation names the file and key. Product names never appear in this crate.
