## Build

- Nodes: a local path as a tree (keyed on its tree digest), an archive unpacked to a tree, a URL downloaded and checked against the lock digest.
- Downloads resume; a digest mismatch is a failure, never a warning.

## Proof

Tests: each node's output digest; a wrong digest fails with both digests.
