## Build

- Board + components + product + lock + recipes -> one `GraphDocument` (`format: daedalus.graph`, `schema_version`, `requires` from the registry).
- The graph is validated by the Daedalus planner before anything runs; a plan error names the description that caused it.
- Every node gets daedalus.node.fusion: false, so fail-fast and cancel can stop between steps (found in A2).
- Every node gets its step's name in its config, so the body and `steps.log` can name it: a node body cannot see its node label (Daedalus `Ctx` has no node identity; found in A3).
